# Fangame Fnaf (Nom à voir)

### Programmation

- Je travaille en **C++20**
- Projet développé en **C++20** avec la bibliothèque **Raylib** et les bibliothèques standard **C++**
- Je programme sur **VSCode**
- Je crée mes assets à l'aide de **Blender**
- Je compile avec **CMake**
- Je versionne avec **Git**

Voici la liste de tous mes outils :

- [Raylib](https://www.raylib.com/)
- [Blender](https://www.blender.org/)
- [VSCode](https://code.visualstudio.com/)
- [CMake](https://cmake.org/)
- [Git](https://git-scm.com/)

## Contrôles

| Action | Contrôle |
|--------|----------|
| Interagir avec l'environnement | Souris |
| Activer le mode de debug | F1 |

## Installation / Compilation

```bash
git clone https://github.com/Desoxyno/FangameFnaf.git
cd FangameFnaf
mkdir build
cd build
cmake ..
make
```
